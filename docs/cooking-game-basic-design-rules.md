A simplified version of the popular mobile cooking time management games like cooking frenzy
but this one is Made for elders so we dont have the full cooking process , its just about serving the requests
The goal of each level is to complete the requests of all customers in each levl.
Each customer comes in with a request of 1-3 food items and their own 'patience level' which is a timer bar that counts down
the customer request ui is adjusted according to the number of items they reqeust
the user sees all the food items available in that level
each food item goes through 4 phases, prepare > cooking > ready > burnt
customer can be served each food item only once it is in the ready state
once it is in a burnt state it must be deleted with a clear button click to make room for another dish

all the paramters of a level should be configurable
